# Todo App (Тестовое задание ZalogHub)

Реализация списка задач по требованиям тестового задания на вакансию Junior Frontend Developer в компанию ZalogHub.

## Реализованная функциональность

- Добавление задачи (с валидацией пустых строк и пробелов)
- Переключение статуса выполнения задачи (с визуальным отличием)
- Удаление задачи
- Фильтрация: Все / Активные / Выполненные
- Автосохранение задач в `localStorage`
- Адаптивный и чистый UI

## Стек технологий

- React (TypeScript)
- Vite
- Tailwind CSS
- Lucide React (легковесные иконки, можно отказачаться в пользу обычных svg)

## Инструкция по запуску

```bash
# Клонирование репозитория
git clone <URL_РЕПОЗИТОРИЯ>
cd zaloghub-todo

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка типов и сборка
npm run build
